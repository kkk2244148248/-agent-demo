# 出差远程访问：Tailscale（不买云服务器）

> 适用场景：老板不想交云服务器费用，但业务员出差仍要使用「海贸工作台」。  
> 做法：办公室留 **一台常开电脑** 跑本系统，出差员工用 Tailscale 组网后访问。

---

## 1. 为什么选 Tailscale

| 点 | 说明 |
|----|------|
| 费用 | 个人/小团队免费档通常够用（约 1–20 人） |
| 无需公网 IP | 不用路由器端口映射、不用备案 |
| 相对安全 | 不是把系统裸奔到公网，只有加入同一 Tailnet 的设备能访问 |
| 使用简单 | 装客户端登录后，像在同一局域网 |

**注意：**  
- 不交「云服务器租用费」，但仍需要办公室有一台 **不关机** 的电脑。  
- 千问 API 仍按用量计费（模型费 ≠ 服务器费）。

---

## 2. 架构示意

```
出差员工手机/笔记本
        │
        │ Tailscale 加密组网（免费）
        ▼
办公室常开电脑（跑海贸工作台）
  ├── 后端 API  :8000
  ├── 前端 Vue  :5173
  └── 本地 BGE-M3 + 数据文件
```

出差员工浏览器打开：

```text
http://<办公室电脑的Tailscale IP>:5173
```

## 3. 办公室侧（管理员做一次）

### 3.1 准备机器

- 选一台相对稳定的 Windows 电脑（建议接电源、禁止休眠）
- 安装本项目依赖，确保本地可打开：http://localhost:5173
- 确认后端 `8000`、前端 `5173` 能启动

### 3.2 安装 Tailscale

1. 打开官网安装客户端：https://tailscale.com/download  
2. 用公司统一账号登录（建议单独建一个团队账号，不要用私人散装号）
3. 登录后在管理后台能看到这台设备在线

### 3.3 记下访问地址

在办公室电脑的 Tailscale 客户端里查看本机 IP，形如：

```text
100.x.y.z
```

或使用 MagicDNS 主机名（若已开启），形如：

```text
office-pc.tail-xxxxx.ts.net
```

### 3.4 启动服务（办公室电脑）

```bash
# 终端 1：后端
cd d:\外贸多agent项目
python run_api.py

# 终端 2：前端（需监听 0.0.0.0，否则外机访问不到）
cd d:\外贸多agent项目\frontend
npm run dev -- --host 0.0.0.0 --port 5173
```

说明：

- Vite 已配置 `--host` 时可被局域网/Tailscale 访问  
- API 已监听 `0.0.0.0:8000`  
- 前端通过 Vite 代理访问 `/api`，出差员工 **一般只需打开 5173**

### 3.5 建议开机自启（可选）

- Windows「任务计划程序」：开机后自动执行 `python run_api.py` 与 `npm run dev`
- 或写一个 `start_trade_desk.bat` 双击启动两个窗口
- 电源选项：关闭「睡眠」，插电运行

---

## 4. 出差员工侧

1. 安装 Tailscale（Windows / macOS / Android / iOS 均可）  
2. 登录 **同一个 Tailnet 账号/被管理员邀请的账号**  
3. 确认能看到办公室那台设备在线  
4. 浏览器打开：

```text
http://100.x.y.z:5173
```

把 `100.x.y.z` 换成办公室电脑的实际 Tailscale IP。

5. 左下角选择自己的员工身份后正常使用（询盘、审批、跟进等）

---

## 5. 管理员日常检查清单

- [ ] 办公室电脑在线且未睡眠  
- [ ] Tailscale 图标显示 Connected  
- [ ] `http://127.0.0.1:5173` 本机可打开  
- [ ] 出差设备 Tailscale 已登录同一网络  
- [ ] 防火墙未拦截 5173 / 8000（仅需对 Tailscale 虚拟网卡放行即可）

Windows 防火墙若拦截，可放行端口或允许 Python/Node 入站。

---

## 6. 安全建议（小公司也要做）

1. **只邀请本公司员工设备**进 Tailnet，离职立刻移除  
2. 工作台仅内部使用，不要发到公网群  
3. 对外发信仍走「发送审批」，AI 草稿不能自动外发  
4. 定期备份 `storage/` 与 `data/`（U 盘或网盘即可）  
5. 办公室电脑设开机密码，勿共用游客账户

## 7. 常见问题

### Q1：打开网页一直转圈 / 连不上？

- 办公室电脑是否关机/睡眠？  
- 两边 Tailscale 是否都显示在线？  
- 是否用了 `localhost`（出差端应使用办公室的 `100.x.y.z`）  
- 前端是否用 `--host 0.0.0.0` 启动？

### Q2：能打开页面但接口失败？

- 办公室后端 `8000` 是否在跑？  
- 看办公室终端是否有 `/api/...` 请求日志  

### Q3：免费版人数不够？

- 先清退不用的设备  
- 或升级 Tailscale 付费档（通常仍远低于云服务器 + 运维成本）

### Q4：能不能不用装客户端？

- 可以再考虑 Cloudflare Tunnel（另文记录）  
- 对「完全零安装」更友好，但暴露面与配置略不同  
- 当前默认推荐仍是 Tailscale

## 8. 和「买云服务器」对比

| 方案 | 费用感 | 数据位置 | 适合 |
|------|--------|----------|------|
| 云服务器 24h | 每月固定开支 | 云上 | 要公网域名、多人高可用 |
| **办公室电脑 + Tailscale** | 几乎 0 服务器费 | 本地 | **当前小外贸团队** |
| 每人本地各装一套 | 0 | 分散难同步 | 不推荐 |
