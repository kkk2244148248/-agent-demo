## 快速对照

### 对话主链路

```
用户 → Assistant.vue
  → POST /api/assistant/chat
  → run_supervisor_desk()
      → supervisor_select()
          ① 附件 → doc_parse（parse + extract_quote + doc_vs）
          ② CRM 词 → crm_action（写入/搜索/360/逾期/跳转）
          ③ 否则 match_skill → 对应子 Agent
      → domain_agent_select_tools()  # 含细分启发式
      → run_selected_tools()         # handlers + extended
  → 审计；inquiry_id → 写回 pipeline
```

### Skill 优先级（15）

`crm_action` → `doc_parse` → `full_rfq` → `followup_mail` → `email_todos` → `sample_track` → `cert_check` → `vendor_risk` → `cost_estimate` → `ask_factory` → `reply_overseas` → `compare_quotes` → `parse_requirement` → `find_vendor` → `kb_qa`
